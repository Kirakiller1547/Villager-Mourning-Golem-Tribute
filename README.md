A custom Minecraft mod that adds dramatic and emotional events upon the death of an Iron Golem! 

When an Iron Golem dies, neighboring Villagers will walk over to pay their respects. A gravestone spawns at the site of death, and a tribute song plays to honor the fallen defender.

---

## 📸 Overview & Features

* **🪦 Gravestone Spawning:** Automatically places a custom gravestone block at the Iron Golem's death location.
* **🚶 Villager Pathfinding:** Nearby villagers move towards the gravestone to mourn.
* **🎵 Custom Tribute Sound:** Plays a mourning song (*Kamin von Emin und Jony*) when the Iron Golem perishes.
* **🌐 Multi-Language Support:** Fully localized in English (`en_us`) and German (`de_de`).

## 🛠️ Requirements & Installation

Make sure you have installed the correct versions before launching the game:

| Requirement | Version | Link |
| :--- | :--- | :--- |
| **Minecraft** | `1.21.4` | — |
| **Fabric Loader** | `>=0.16.0` | [FabricMC](https://fabricmc.net/) |
| **Fabric API** | `0.119.4+1.21.4` | [CurseForge](https://www.curseforge.com/minecraft/mc-mods/fabric-api) / [Modrinth](https://modrinth.com/mod/fabric-api) |

### Installation Steps
1. Download and install **Fabric Loader** for Minecraft **1.21.4**.
2. Download **Fabric API** (`fabric-api-0.119.4+1.21.4.jar`).
3. Place `fabric-api-0.119.4+1.21.4.jar` and this mod's `.jar` file into your `.minecraft/mods` folder.
4. Launch the game!
